# 信息安全导论作业 - S-AES 加解密系统

本项目基于 Java 语言（结合 Swing 与 FlatLaf 现代主题库）完整实现了简化版 AES（S-AES）算法。
除了基础的核心加解密功能外，本项目还按要求完成了多重加密、中间相遇攻击破解、ASCII 字符串扩展以及 CBC 工作模式的扩展任务。
## 🛠️ 开发环境与运行指南
- **编程语言**：Java (JDK 8 及以上)
- **图形界面**：Java Swing + FlatLaf 3.4
- **依赖库**：`flatlaf-3.4.jar`（已包含在项目根目录中）
**如何运行：**
在终端（CMD）中进入项目根目录，执行以下命令：
# 1. 编译项目
javac -encoding UTF-8 -cp "flatlaf-3.4.jar;." core/*.java SAESApp.java
# 2. 启动 GUI 程序
java -cp "flatlaf-3.4.jar;." SAESApp
